Until 24th December 2025 this repo was public,
We should aspire for it to continue to be.

In the PR where these instructions are introduced @huwd included reference to our vulnerability management SLAs.
Out of an abundance of precaution and not knowing if those are official sensitive or not, Huw set the repo to internal visibility only.

This means the di-observable-notebooks now have the same visibility as the policy itself.
We should:

1. Decide if those SLAs should indeed be withheld from the public
2. Decide if there's a smarter way to bring them in (perhaps via a data loader, but unclear where that can be scraped from)
3. Decide if we can remediate just the commit history that covers this
4. Return the repo to the public domain

All other information in this repo should be kept as if it were already in the public domain, and new sensitivities only introduced if we first amend this documents
